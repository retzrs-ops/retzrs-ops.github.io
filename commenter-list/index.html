必要なもの

どちらも無料です。導入は3ステップ、5分ほどで終わります。

わんコメ（OneComme）YouTubeのコメントを取得できる状態にしておく
OBS Studio「カスタムブラウザドック」を使います

導入手順 3ステップ

ダウンロードしたzipを展開（右クリック →「すべて展開」）してから始めてください。

  1. わんコメにフォルダを置く

    1. わんコメを起動し、右上の「…」→「テンプレート」を開く
    2. フォルダのアイコンをクリックして、テンプレートフォルダを開く
    3. 中の custom フォルダに、commenter-list フォルダをフォルダごと入れる
    templates └ custom └ commenter-list ├ index.html └ config.js

    custom フォルダが無い場合は、テンプレートフォルダの直下に入れてください（次の手順のURLから custom/ を抜きます）。

  2. OBSにドックを追加する

    1. OBSのメニュー「ドック」→「カスタムブラウザドック」を開く
    2. ドック名に「コメントした人」、URLに下のアドレスを貼り付ける
    3. 「適用」を押すと、パネルが現れます
    http://localhost:11180/templates/custom/commenter-list/index.html

    パネルはタイトル部分をドラッグして好きな場所に置けます。チャット欄の横がおすすめ。位置が決まったら「ドック」→「ドックをロック」で固定できます。

  3. 動作確認

    1. わんコメのコメントテスターで、名前とコメントを入れて送信
    2. ドックに「1」番として名前が出れば導入完了です

使い方

配信中はドックを見ているだけ。コメントが来ると自動で一覧に追加されます。

操作できること
名前をクリック「挨拶済み」にする（✓が付いて薄くなる）。もう一度クリックで戻る
済を隠す挨拶済みの人を隠し、まだの人だけを表示
A− ／ A＋文字サイズを1pxずつ調整（10〜32px、標準12px）。設定は保存されます
リセット今回のリストを消して最初からにする

表示・非表示

OBSのメニュー「ドック」で「コメントした人」のチェックを付け外しします。閉じている間のコメントも、次に開いたときにわんコメから取り込まれます。

リストの区切り

前回のコメントから4時間空くと、次のコメントで自動的に新しいリストになります。わんコメの「コメントクリア」や「リセット」ボタンでも区切れます。同じ配信中にOBSを再起動しても、リストは消えません。

ニックネームと設定

ニックネームは、わんコメの「コテハン」で付けた名前が自動で使われます。それ以外の設定は config.js をメモ帳で編集します。

設定項目初期値内容
includeOwnerfalsetrue で、配信者本人のコメントもリストに入れる
autoResetHours4この時間コメントが空くと新しいリストにする。0 で自動リセットしない
resetOnCleartrueわんコメの「コメントクリア」でリストもリセット
nicknames（空）手動のニックネーム。コテハンより優先

nicknames は1人1行で書き、行頭の // を消すと有効になります。保存後、ドックを再読み込みしてください。

nicknames: { "@example_handle": "れいくん", "山田太郎": "やまちゃん", },

困ったとき

ほとんどは「わんコメを起動してから、ドックを右クリック →『再読み込み』」で直ります。

症状対処
「わんコメに接続できません」わんコメを起動してから、ドックを再読み込み。メニューに無ければOBSを再起動
真っ白／ページが見つからないURLの打ち間違いか、フォルダの場所違い。custom に入れたなら URL に custom/ があるか確認
名前が出ないわんコメでYouTubeの配信が登録され、コメントを取得できているか確認
前の配信の人が残っている「リセット」を押す。自動の区切りは config.js の autoResetHours で調整
ニックネームが反映されないconfig.js のカンマや引用符を確認し、保存後にドックを再読み込み

アップデート・削除

アップデートは、新しい index.html を commenter-list フォルダに上書きするだけです。config.js を上書きしなければ、自分の設定は残ります。削除するときは、フォルダを消してから、OBSの「カスタムブラウザドック」で該当の行を消してください。

わんコメとOBSがあれば、今日の配信から使えます。
