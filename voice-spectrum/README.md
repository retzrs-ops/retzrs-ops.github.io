# こえスペクトル

マイクで録音した声（または音声ファイル）から、スペクトログラムや声の特徴（ジッター・シマー・HNR・CPP・ビブラートなど）を表示するWebアプリです。処理はすべて端末の中で行い、録音した音声はどこにも送信しません。

## 使い方

1. `index.html` をHTTPSで配信されたページとして開きます。
2. 「録音する」を押してマイクを許可するか、「ファイルを選ぶ」で録音済みの音声を読み込みます。

## テスト

```bash
node voice-spectrum/test/analysis.test.js
```

`index.html` の `/*CORE-START*/` 〜 `/*CORE-END*/` の解析処理を、合成した声で検証します。

## 免責

測定結果は目安です。マイクや部屋の響き、その日の体調で変わります。
