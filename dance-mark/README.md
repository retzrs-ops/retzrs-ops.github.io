# ダンスマーク

カメラに映った自分の手首・指先・足先で、画面中央から8方向に飛び出すマークに触れるリズムゲームです。音楽はブラウザ内で生成するため、音源ファイルは不要です。

## 遊び方

1. `index.html` をHTTPSで配信されたページとして開きます。
2. 「スタート」を押し、カメラを許可します。
3. 全身がカメラに映る位置に立ちます。
4. マークが判定位置に来た拍で、手首・指先・足先を重ねると得点になります。

判定はPERFECT（±0.08秒）とGOOD（±0.2秒）の2段階です。外すとMISSになり、コンボが途切れます。

## 動作環境

- カメラ付きのPCまたはスマートフォンの最新ブラウザ（Chrome、Edge、Safari など）
- HTTPS、またはlocalhostでの配信（カメラの利用に必要です）
- 初回起動時に姿勢認識モデル（MediaPipe Pose Landmarker）を外部から読み込むため、ネットワーク接続が必要です

## 外部ライブラリ・データ

- MediaPipe Tasks Vision 0.10.14（jsDelivr経由）
- Pose Landmarker lite モデル（Google Storage経由）
